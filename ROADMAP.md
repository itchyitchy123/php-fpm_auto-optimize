# Roadmap

## Near term

- Validate behavior on supported distribution containers in CI.
- Publish signed, checksummed standalone releases.
- Complete Debian and RPM package builds.

## Later

- Optional FPM status-page observations and slow-log signals.
- Per-pool proportional-set-size sampling where kernel permissions allow it.
- Report comparison and historical trend tooling.

The default mode will remain read-only. Scheduled operation will remain
report-only unless an administrator explicitly requests application.
