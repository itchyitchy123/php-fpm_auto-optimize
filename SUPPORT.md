# Support

Use a GitHub issue for reproducible bugs and feature requests. Include the tool
version, operating system, PHP packaging source, redacted dry-run output, and
the exact command used. Do not include credentials, customer names, or private
paths.

Questions about PHP application performance, database sizing, Apache tuning,
or capacity planning outside PHP-FPM are beyond this project's support scope.
Security reports belong in the private channel described in `SECURITY.md`.
