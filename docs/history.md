# Project history

FPM Lens began as a small Bash capacity calculator. That prototype established
the operational problem but eventually became difficult to test and extend.

Version 0.1.0 is an independently designed Rust application with a typed model,
evidence artifact, constraint-based planner, terminal review interface, and
staged renderer. It does not embed or call the historical script.

The last Bash implementation is permanently available from the
`bash-prototype-v0.5.0` Git tag. Keeping it outside the default branch makes the
current product and language clear while retaining transparent provenance.
